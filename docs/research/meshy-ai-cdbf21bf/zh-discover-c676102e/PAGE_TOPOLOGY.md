# Page topology

```text
WorkspacePage
├── WorkspaceHeader
│   ├── Menu trigger + Meshy wordmark
│   └── Credits / membership / gifts / notifications / profile
├── TopologyStage
│   ├── SurroundGallery
│   │   ├── SharedQuadrilateralFace × 168
│   │   └── AnimatedModelFace × 39
│   ├── CreationWorkspace (centered above gallery)
│   │   ├── Greeting
│   │   ├── ModeSwitch
│   │   └── CreationCommandCenter
│   │       ├── Prompt / image input drop zone
│   │       ├── Sample image selectors
│   │       └── Detail level + generate controls
│   └── GalleryCategoryRail
├── ModelPreviewDialog (conditional)
└── UpgradeDock
```

The creation workspace is the stable focal surface. The community model gallery becomes the surrounding topology skin and continues beneath it for a finite 2–3 screen experience.
