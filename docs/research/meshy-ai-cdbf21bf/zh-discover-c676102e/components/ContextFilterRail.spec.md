# ContextFilterRail

## Purpose

Let users reorganize the same capabilities around a concrete production goal.

## Geometry

- Single horizontal desktop row below the capability-section introduction.
- 34–38px pill height, 10px gap.
- Sticky behavior is intentionally omitted; the rail belongs to the mesh section.

## Items

- 全部能力
- 游戏开发
- 3D 打印
- 产品设计
- 角色动画

## States

- Active: warm-white surface, black text, subtle green edge glow.
- Inactive: translucent dark surface, gray text, faint border.
- Hover/focus: brighter border and text.
