# Output plan

## Product decision

Rebuild the signed-in Meshy experience as a desktop-only creative workspace. Preserve the recognizable workspace shell, dark green/blue atmosphere, greeting, creation command center, and discovery filters. Recompose the original model gallery as irregular four-sided image cells surrounding the central operation console.

## Route

- Source reference: `https://www.meshy.ai/zh/discover` after sign-in
- Local implementation: `/`
- Target viewport: 1440 x 900 and wider desktop screens
- Content depth: roughly 2–3 desktop viewports; no infinite loading

## Deliverables

1. Signed-in workspace header and account controls.
2. Personalized greeting and Quick Generate / Agent mode switch.
3. Central image-to-3D creation panel with interactive sample selection and settings.
4. Original-style gallery category rail.
5. A 12 × 14 shared-vertex topology containing 168 compact quadrilateral faces.
6. Thirty-nine selected model faces with proportional images and rig, texture, or component hover demonstrations.
7. Large model preview opened from a populated face.
8. Finite desktop experience with representative content, keyboard focus states, and reduced-motion support.

## Non-goals

- Mobile and tablet layouts.
- Authentication, uploads, generation APIs, or billing.
- A separate technical capability-card section.
- Unbounded or server-backed feeds.
