# Behaviors

## Creation command center

- Switching modes changes the command-center label and helper copy.
- Clicking a sample marks it selected and updates the preview treatment.
- Detail level cycles between Standard, Refined, and Production.
- Generate remains a prototype action and reports the selected setup inside the button.

## Surrounding gallery

- A 12 × 14 shared lattice forms 168 connected, compact quadrilateral faces.
- Only 39 selected faces contain proportionally scaled 3D model renders; the rest expose the topology background.
- Hover/focus demonstrates automatic rigging, texture before/after, or component separation inside the face.
- Clicking a cell opens a large dark model preview.
- Escape, backdrop, or the close button dismisses the preview.

## Motion and accessibility

- Hover movement is small and preserves the four-corner geometry.
- Focus-visible styling matches the green/blue glow.
- Reduced-motion users receive opacity-only transitions.
- Every interactive control has an accessible label and native button semantics.
