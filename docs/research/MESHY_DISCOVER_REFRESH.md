# Meshy Discover refresh reference

Source inspected: https://www.meshy.ai/zh/discover

Desktop scope only. The customized workspace remains the primary product surface; the
source page was used only for live typography comparison, Agent capability inventory,
and community model covers.

## Observed desktop typography

- Main greeting: 32px / 40px.
- Primary controls and generation actions: 14px / 20px.
- Supporting body and hints: 12–14px / 18–20px.
- Gallery titles: 12–14px; creator and metadata should not fall below 11px.

## Agent capability inventory

The source Agent surface exposes attachment and skill actions. This prototype keeps the
relevant creation actions in a compact menu: 图片转 3D、礼物设计、批量生成模型、草图转手办、
人物配色实验、3D 打印学习，并加入 PBR 贴图和骨骼绑定以支持提议的工作流。

## Community assets

The source page was sampled through roughly three desktop scrolls. Twenty-eight unique,
currently visible community model covers were downloaded to
public/images/meshy-gallery/community/. The app combines those with three existing
unique furniture references for a 31-card gallery. No remote images are required at
runtime.
